Conexión con Gmail

El Client ID se guarda. Al reabrir la app se intenta reconectar en silencio (sin popup) mientras Google recuerde tu consentimiento; si lo revocas o expira, deberás volver a hacer clic en "Conectar con Google".

1

Ir a console.cloud.google.com → crear proyecto

2

APIs y servicios → Biblioteca → Gmail API → Habilitar

3

Credenciales → Crear credenciales → ID de cliente OAuth → tipo: Aplicación web

4

En orígenes autorizados agrega https://claude.ai o tu dominio local

5

Pega el Client ID abajo

Seguimiento de aperturas

Para saber si el destinatario abrió el correo hace falta un pequeño endpoint que reciba el píxel de tracking — la app no puede recibirlo sola. Usa Google Apps Script (gratis, en tu propia cuenta de Google):

1

Crea una Google Sheet nueva

2

Extensiones → Apps Script

3

Pega el código de apps-script/PixelTracker.gs (incluido en este proyecto)

4

Implementar → Nueva implementación → Aplicación web → acceso "Cualquier usuario"

5

Pega la URL de la implementación abajo

Es aproximado: Gmail suele cachear imágenes externas, y si el destinatario bloquea imágenes el píxel no se dispara aunque haya leído el correo.

Seguridad

El Client ID, los CV y las campañas se guardan en este navegador (localStorage). Puedes protegerlos con una contraseña que cifra todo localmente.
